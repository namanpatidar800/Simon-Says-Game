## 🕹️ About the Game

**Simon Says** is the timeless memory challenge — the game shows you a growing sequence of
flashing colors, and it's your job to repeat it back exactly. One wrong move, and it's game over.
How high can you climb? 📈

---

## 🧠 Game Rules

- 🔑 Press **any key** on your keyboard to start the game
- 🎨 Each level adds **one more color** to the sequence
- 🖱️ Repeat the sequence by clicking the buttons in the correct order
- ❌ A wrong click **ends the game**
- 🏆 Your **highest score** is tracked as you play

## ☁️ Deploy on Render (Static Site)

This project is pure static HTML/CSS/JS, so it deploys as a **Static Site** on Render — no backend, no build tools required.

1. Push this repo to GitHub.
2. On Render, click **New +** → **Static Site**.
3. Connect your GitHub repository.
4. Use these settings:

   | Setting | Value |
   |---|---|
   | **Build Command** | *(leave blank)* |
   | **Publish Directory** | `.` |

5. Click **Create Static Site** — Render will deploy it automatically. 🚀

Once deployed, drop your live URL into the badge/link at the top of this README!
